## MySQL vs MariaDB

The user explicitly accepted either MySQL or MariaDB.

S0 selects **MySQL** as the single development/test baseline to avoid maintaining two
equivalent Docker and CI matrices before a production host exists.

This is a technical choice, not a domain choice. MariaDB remains a future migration
candidate if the selected production environment makes it preferable. Such a switch
must occur before concurrency-sensitive slices are finalized and must rerun all
database-specific tests.

The S0 baseline uses the MySQL 8.4 LTS family rather than the moving `latest` tag.

## Why Laravel Sail

Sail is Laravel's first-party Docker development environment. It already supports:

- Linux;
- PHP 8.3 runtime selection;
- MySQL with persistent storage;
- a separate testing database;
- Composer and Artisan execution inside the container.

MP2 uses only the required Sail services. S0 does not add Redis, Selenium, mail
capture, search engines, or other optional services.

MP2 may edit the project-owned `compose.yaml` generated by Sail. It MUST NOT modify
Sail source under `/vendor`.

## Frontend

Filament is the UI baseline.

S0 does not require:

- `package.json`;
- `vite.config.*`;
- npm install;
- `node_modules`;
- a frontend build job.

If Laravel scaffolding creates unused Vite files, they are removed in S0 once it is
verified that no project view references them.

Laravel Sail's runtime image may contain a Node binary as a bundled capability. MP2
does not treat that as a project frontend dependency and does not invoke Node in S0.

Future slices may introduce Vite when a concrete need exists, such as a compiled
Filament theme, Tailwind customization, an npm dependency, or non-trivial JS bundling.

## Application structure

The target structure is deliberately small:

```text
app/
├── Models/
├── Domain/      # only when deterministic domain rules first appear
├── Actions/     # only when explicit mutating operations first appear
├── Filament/
└── Policies/    # when authorization rules are introduced
```

Empty future layers are not created during S0.

## External technical reference

`Capobuf/AssestMe` is evidence that Laravel 13 + Filament 5 + PHP 8.3 and direct
Filament CSS/JS asset registration have worked in an existing project owned by the
same user. MP2 does not copy AssestMe's domain or application code.
