# Data Model: S0 Foundation

S0 intentionally contains no economic domain model.

## User

Technical authentication record required by Laravel/Filament.

Minimum attributes:

- stable primary ID;
- name;
- unique email;
- password hash;
- Laravel timestamps as generated by the selected framework scaffold.

S0 does not add:

- Azienda;
- roles;
- capabilities;
- permission pivots;
- profile/business metadata;
- domain ownership.

Those belong to S1.

## Development administrator

This is not a new table or role type.

It is the `User` selected by:

```text
DEV_ADMIN_EMAIL
```

during local bootstrap.

Bootstrap contract:

- only valid outside production;
- email is the idempotency key;
- password comes from local `.env`;
- rerun does not create another row for the same email;
- the configured `.env` credentials remain usable after normal rerun.

## Databases

### Development database

```text
name: mp2
lifecycle: persistent
reset by normal bootstrap: never
```

### Testing database

```text
name: testing
lifecycle: disposable
destructive migration/reset: allowed only in APP_ENV=testing
```

## Framework tables

Only tables created by the minimal Laravel authentication/migration baseline are
allowed in S0.

Any additional framework table must have an actual S0 use. Do not add queue, cache,
notifications, permission, company or domain tables in advance.
